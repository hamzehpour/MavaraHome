## مستندات تولیدشده

دو فایل از روی خود کد ساخته می‌شوند و نباید دستی ویرایش شوند:

```bash
python3 docs/generate.py          # بازتولید
python3 docs/generate.py --check  # همان چیزی که CI اجرا می‌کند
```

`--check` علاوه بر تازگی آن دو فایل، دو نامتغیر را هم بررسی می‌کند: هر جدول
دیتابیس باید در `03-data-model.md` نام برده شده باشد، و هر کلید تنظیمات باید
از صفحه‌ی تنظیمات پنل قابل دسترس باشد.

## قواعد نگهداری این اسناد

1. **هر واقعیت فقط یک صاحب دارد.** اگر چیزی در `03-data-model` توضیح داده
   شده، بقیه‌ی اسناد به آن **لینک** می‌دهند، کپی نمی‌کنند. کپی یعنی تناقض
   در آینده.
2. **سند بدون کد به‌روز نمی‌شود.** تغییر رفتار = به‌روزرسانی سند مربوطه در
   همان کامیت (بند ۴ از «تعریف کارِ تمام‌شده» در `AGENTS.md`).
3. **اگر چیزی را نمی‌دانی، ننویس که می‌دانی.** جای خالی صادقانه بهتر از
   جمله‌ی حدسی است؛ نمونه‌اش سند `10-state-and-roadmap` که عمداً کاستی‌ها را
   فهرست می‌کند.
4. **`CHANGELOG.md` تاریخچه است، این پوشه وضعیت فعلی.** چیزی که دیگر درست
   نیست را از اینجا حذف کن، نه اینکه کنارش توضیح تاریخی بگذاری.
