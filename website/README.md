# خانه ماورا — وبسایت

سایت عمومی خانه ماورا (رویدادها، رزومه، اعضای تیم) + پنل مدیریت محتوا.

> **به‌روزرسانی (فاز ۱ بازبینی رزرو):** این سایت یک بک‌اند مستقل خودش
> (`backend_cms/`) داشت که مخصوص هاست اشتراکی بدون SSH ساخته شده بود.
> بعد از خرید یک VPS واقعی، آن دلیل دیگر وجود نداشت، و نگه داشتنش یعنی
> دو منبع داده‌ی جدا برای محتوا (شکاف واقعی که در بازبینی محصول پیدا شد
> — رویدادی که در `backend_cms` ساخته می‌شد، در دیتابیس بات اصلاً وجود
> نداشت). `backend_cms/` حذف شد؛ سایت الان دوباره مستقیم به همان
> بک‌اند یکپارچه‌ای وصل است که ربات تلگرام هم استفاده می‌کند
> (`bot/api/server.py`) — یک دیتابیس، یک منبع حقیقت. جزئیات کامل در
> `CHANGELOG.md` (بخش «reservation migration — phase 1»).

## معماری

```
سرور (یک VPS)
   │
   ▼
Nginx
   │
   ├── website/ (این پوشه) — فایل‌های استاتیک، مستقیم از دیسک
   │
   └── /api/v1/*  و  /media/*  →  proxy  →  bot/api/server.py (پورت 8788)
                                                  │
                                                  ▼
                                          دیتابیس یکپارچه (SQLite، در bot/data/)
                                                  ▲
                                                  │
                                        ربات تلگرام (پروسه‌ی جدا، همان دیتابیس)
```

`website/` خودش کد بک‌اند ندارد — فقط `index.html` + `pages/` + `assets/`
است. برای اجرا/استقرار به `bot/README.md` و `bot/DEPLOYMENT.md` مراجعه
کن؛ همان یک راهنما سایت و ربات و API را با هم توضیح می‌دهد، چون همه از
یک پروسه اجرا می‌شوند.

## اجرای محلی برای تست

```bash
cd ../bot
ENV=test python3 migrate.py       # اسکیمای دیتابیس تستی را می‌سازد
python3 create_web_admin.py       # یک حساب ادمین سایت بساز
python3 -m api.server             # روی پورت 8788 بالا می‌آید
```

سایت را با یک سرور استاتیک ساده (یا Live Server در VS Code) باز کن. اگر
سایت و API روی پورت‌های متفاوت اجرا می‌شوند (حالت تست محلی)، قبل از لود
شدن اسکریپت‌ها این خط را در کنسول مرورگر یا یک `<script>` بگذار:
```js
window.MAAVARA_API_BASE = 'http://localhost:8788';
```
در حالت واقعی (production)، API زیر همان دامنه‌ی سایت (مسیر `/api/v1/`)
قرار می‌گیرد، پس این خط لازم نیست — `MAVARA_API_BASE` پیش‌فرض خالی
می‌ماند (هم‌مبدأ).

## رزرو کجاست؟

فعلاً فقط در `bot/` (ربات تلگرام) — دکمه‌ی «رزرو» روی هر رویداد یک لینک
به تلگرام/تلفن است. طبق پلن بازبینی محصول (`CHANGELOG.md`)، فازهای بعدی
همین قابلیت رزرو را مستقیم به این سایت هم می‌آورند؛ چون هر دو از حالا
به یک دیتابیس مشترک وصل‌اند، آن انتقال دیگر نیازی به بک‌اند یا دیتابیس
جدید ندارد — فقط UI.
