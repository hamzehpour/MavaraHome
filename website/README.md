# خانه ماورا — وبسایت

سایت عمومی خانه ماورا (رویدادها، رزومه، اعضای تیم) + پنل مدیریت محتوا.
**بدون رزرو آنلاین** — دکمه‌ی «رزرو» روی هر رویداد فقط یک لینک به
تلگرام/تلفن است (از فیلدهای همان رویداد). رزرو واقعی، کاملاً جدا، از
طریق ربات تلگرام (پوشه‌ی `bot/` در ریشه‌ی این ریپو) انجام می‌شود.

> این پروژه قبلاً به یک بک‌اند Node.js مشترک (`backend/`، دیتابیس
> PostgreSQL) وصل بود که فایل‌های آن هنوز اینجا هستند اما دیگر استفاده
> نمی‌شوند — منسوخ شده، فقط برای مرجع تاریخی نگه داشته شده. بک‌اند واقعی
> امروز `backend_cms/` است (پایین توضیح داده شده).

## ساختار

```
website/
├── index.html, pages/, assets/   ← سایت استاتیک (frontend)
├── media/                        ← عکس/ویدیوی آپلودی (فایل معمولی، مستقیم سرو می‌شود)
├── backend_cms/                  ← بک‌اند واقعی — Flask (پایتون)، SQLite خودش
│   ├── app.py                    ← کل API
│   ├── DEPLOYMENT.md             ← نصب روی هاست اشتراکی (سی‌پنل/دایرکت‌ادمین)
│   └── create_admin.py           ← ساخت حساب ادمین اول
└── backend/                      ← منسوخ (Node.js قدیمی) — استفاده نمی‌شود
```

## اجرای محلی برای تست

```bash
cd backend_cms
pip install -r requirements.txt
cp .env.example .env
python3 -c "import secrets; print(secrets.token_hex(32))"   # مقدار را در .env جای JWT_SECRET بگذار
python3 create_admin.py                                       # یک حساب ادمین بساز
python3 app.py                                                 # روی پورت 8790 بالا می‌آید
```

سایت را با یک سرور استاتیک ساده (یا Live Server در VS Code) باز کن. اگر
سایت و بک‌اند روی پورت‌های متفاوت اجرا می‌شوند (حالت تست محلی)، قبل از
لود شدن اسکریپت‌ها این خط را در کنسول مرورگر یا یک `<script>` بگذار:
```js
window.MAAVARA_API_BASE = 'http://localhost:8790';
```
در حالت واقعی (production)، بک‌اند زیر همان دامنه‌ی سایت (مسیر `/api`)
قرار می‌گیرد، پس این خط لازم نیست — `MAVARA_API_BASE` پیش‌فرض خالی
می‌ماند (هم‌مبدأ).

## استقرار روی هاست واقعی

به `backend_cms/DEPLOYMENT.md` مراجعه کن — برای هاست اشتراکی (سی‌پنل
«Setup Python App» یا معادل دایرکت‌ادمین) نوشته شده؛ نیازی به SSH
ندارد، ولی اگر پلن هاست شما SSH هم داشته باشد (مثل پکیج «پایتون»ی
ایران‌سرور)، همان‌جا توضیح داده چطور از آن هم استفاده کنید.

## رزرو کجاست؟

هیچ‌جای این سایت — عمداً. طبق طراحی، `website/` فقط محتوا را نشان
می‌دهد؛ کل چرخه‌ی رزرو (سانس، پرداخت، بلیت، پیام‌رسانی، حساب مشتری) در
`bot/` (پروژه‌ی کاملاً جدا) پیاده‌سازی شده — به `bot/README.md` مراجعه
کن.
